СВОЯ ИГРА online - игра на облачном сервере (без туннелей)
==========================================================

Идея: игра работает не на вашем компьютере, а на бесплатном облачном
хостинге Render. У неё постоянная ссылка вида https://svoya-igra-xxxx.onrender.com
Ведущий и игроки открывают одну и ту же ссылку. Тяжёлых программ и туннелей
не нужно.

ОДИН РАЗ: размещение игры (около 10 минут)
------------------------------------------
Шаг 1. Аккаунт на GitHub (бесплатно): https://github.com/signup
Шаг 2. Создайте репозиторий: кнопка "+" вверху справа - "New repository".
        Имя: svoya-igra. Видимость: Public (так проще). Нажмите Create.
Шаг 3. На странице нового репозитория нажмите "uploading an existing file".
        Перетащите в окно ВСЕ файлы из этой папки (index.html, server.py,
        render.yaml, README.txt), внизу нажмите "Commit changes".
Шаг 4. Аккаунт на Render (бесплатно): https://render.com , войдите через GitHub.
Шаг 5. На Render: "New +" - "Blueprint" - выберите репозиторий svoya-igra -
        "Apply". (Если Blueprint не предлагается: "New +" - "Web Service",
        репозиторий svoya-igra, Runtime: Python, Build Command: echo ready,
        Start Command: python server.py, Instance Type: Free, в Environment
        добавьте CLOUD = 1.)
Шаг 6. Подождите 2-3 минуты, пока статус не станет "Live". Вверху страницы
        будет ссылка вида https://svoya-igra-xxxx.onrender.com . Это адрес игры.

КАК ИГРАТЬ
----------
- Ведущий открывает ссылку, выбирает "Ведущий", вводит пароль.
- Игроки открывают ту же ссылку: на компьютере "Экран игры", на смартфоне "Кнопка".
- Вопросы ведущего хранятся в браузере ведущего (по этой ссылке). Всегда
  открывайте игру ведущим именно по этой ссылке и в том же браузере.
  Библиотеку можно сохранить в файл в редакторе.

ВАЖНО ЗНАТЬ
-----------
- Бесплатный тариф "засыпает" через 15 минут без посетителей. Первое открытие
  после сна занимает около минуты. ОТКРОЙТЕ ссылку за 5 минут до игры.
- Если сервер перезапустится, файлы картинок/аудио/видео пропадут с сервера:
  игра передаст их заново в начале раунда.
- Ссылку знает кто угодно, у кого она есть. Ведущий защищён паролем.
- Чтобы остановить игру, в Render: Settings - Suspend Service.

Другие хостинги
---------------
Подойдёт любой, где можно запустить Python: команда  python server.py
Игра берёт порт из переменной PORT. Для запуска не на Render задайте CLOUD=1.
